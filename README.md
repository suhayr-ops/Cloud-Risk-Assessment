# Cloud-Risk-Assessment

## Aim of the project

The aim of this project is to assess cyber and cloud security risks within a small cloud-based system hosted on Amazon Web Services, identify key security weaknesses, evaluate their potential business impact, and propose risk-based control recommendations aligned with recognised security frameworks such as ISO 27001 and NIST.

## Objectives (What I Hope to Learn)

### 1. Understand cloud risk, not just cloud security
- Learn how technical cloud misconfigurations can translate into real business risks  
- Develop a risk-based mindset by thinking in terms of likelihood, impact, and consequence rather than isolated vulnerabilities  

### 2. Apply a structured cyber risk assessment process
- Identify and classify key cloud assets  
- Perform systematic threat modelling using the STRIDE framework  
- Evaluate risks using a likelihood × impact scoring approach  

### 3. Assess common cloud security failures
- Analyse the risks associated with over-privileged IAM users and roles  
- Evaluate data exposure risks caused by publicly accessible cloud storage  
- Identify weaknesses in network security controls, such as overly permissive access rules  

### 4. Recommend proportionate security controls
- Propose control recommendations that are appropriate to the severity of each identified risk  
- Map recommended controls to recognised frameworks, including ISO 27001 and the NIST Cybersecurity Framework  

### 5. Communicate risk in a professional way
- Produce a concise executive summary suitable for non-technical stakeholders  
- Develop and maintain a structured risk register  
- Practice translating technical findings into clear, business-focused language


## Project Scope & Assumptions

### In Scope
- Cloud infrastructure hosted on AWS
- Identity and Access Management (IAM)
- Data storage (S3)
- Virtual compute resources (EC2)

### Out of Scope
- Penetration testing
- Application source code review
- Physical security controls

### Assumptions
- Organisation has limited cyber maturity
- Cloud security is shared between provider and client
- GDPR applies due to customer data storage
